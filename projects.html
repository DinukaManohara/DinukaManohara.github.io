Projects

A mix of research prototypes and side projects, spanning IoT platforms, mobile apps, and machine learning.

MOBIsense Community Mobile App

A mobile app providing disaster risk information to communities in hazard zones — live river-level sensor readings, evacuation centre details, and emergency contacts. Built in collaboration with the Department of Irrigation Sri Lanka and Lions Club Sri Lanka as part of the MOBILISE project; I was the lead engineer.

Flutter Dart Node.js PostGIS Azure

MOBILISE IoT Web Platform

An IoT sensor platform, funded by the Global Challenges Research Fund (UK), that integrates disjointed sensor networks across Sri Lankan government agencies to produce real-time flood and landslide hazard information. I was the lead engineer.

React Node.js PostGIS GeoServer Azure

Venomous Snake Detector for Indigenous Sri Lankan Snakes

Machine learning models — based on AlexNet, YOLOv3, Mask-RCNN, and an ensemble approach — to classify whether a snake is venomous from head shape, skin pattern, and tail features.

Computer Vision PyTorch

Parallel Algorithms for Densest Subgraph Discovery

My final-year undergraduate R&D project: a novel, highly scalable parallel algorithm based on graph cores to approximate the densest subgraph, plus a shared-memory implementation of an existing algorithm by Bahmani et al. for comparison. Supervised by Dr. Saliya Ekanayake and Prof. Indika Perera.

C++ OpenMP Graph Algorithms

Epidemic Data Collection and Reporting System

A mobile app and IoT device to collect epidemic data from hospitals, built for the Embedded Database Systems module — React Native for the app, and Arduino with ESP8266 Wi-Fi modules and an SD card reader for the device.

React Native Arduino IoT
