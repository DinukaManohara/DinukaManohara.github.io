Starting This Blog

By Dinuka Manohara

I've wanted a place to write in public for a while — somewhere to think out loud about projects, papers, and the small technical decisions that don't fit anywhere else. This is that place.

What to expect

Mostly short, practical posts: how a project came together, notes from something I read, or a problem I ran into and how I solved it. Nothing polished for its own sake — just honest notes.

How this site works

The whole site is static HTML, CSS, and a small amount of JavaScript for the mobile menu — no build step, no framework. Each page lives as its own .html file, and every blog post is a file inside the blogs/ folder, styled with the same shared stylesheet in css/style.css. It's hosted for free on GitHub Pages, straight from this repository.

Simple tools, kept close to the metal, are easier to maintain for years than anything clever.

If you want to do the same, feel free to fork this repository and swap in your own content — the layout is meant to be easy to adapt.
